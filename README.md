# Documentation

### Run Scripts

#### Send Code to Robot
```bash
py -3 -m robotpy deploy
```
* Make sure you are connected to the radio's network
* Make sure the terminal is directed to `rebuilt-2026\rebuilt-2026`

#### Test Code
```bash
py -3 -m robotpy test
``` 

### Button Bindings
`Tank Drive` --> Uses X and Y axes

`Left Trigger` --> Intake

`Right Trigger` --> Shooting (Hold for more than 1 second to shoot)

`Button A` --> Extract ball (if it gets stuck or use to pull ball in when its already in the container)

`Left Bumper` --> Climber down

`Right Bumper` --> Climber up
